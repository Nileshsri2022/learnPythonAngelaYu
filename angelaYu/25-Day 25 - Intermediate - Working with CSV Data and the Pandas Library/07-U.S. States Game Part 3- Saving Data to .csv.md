### 1. The Exit + Save Feature

Typing `Exit` ends the game and writes a **study list** of missed states:

```python
if answer_state == "Exit":
    missing_states = [state for state in all_states if state not in guessed_states]
    new_data = pandas.DataFrame(missing_states)
    new_data.to_csv("states_to_learn.csv")
    break
```

* List comprehension (formally taught on Day 26, previewed here): every state not yet
  guessed.
* `pandas.DataFrame(list)` — a one-column table, straight to CSV.

---

### 2. Why This Feature Matters

The game is now a **learning tool**: quit anytime, and your next session starts from a
personalised CSV of what you still don't know. Data in a file = state that survives.
