---

### 1. The Game

A Sporcle-style quiz on a blank US map (provided as `blank_states_img.gif`):

* A pop-up asks *"Enter a state's name"*.
* Correct guesses appear **written on the map at the state's location**.
* Score in the title bar; wrong guesses just re-prompt.
* Type `Exit` to stop and save the states you still need to learn.

---

### 2. The Setup

```python
import turtle

screen = turtle.Screen()
screen.title("U.S. States Game")
image = "blank_states_img.gif"
screen.addshape(image)      # register the GIF as a shape
turtle.shape(image)

answer_state = screen.textinput(title="Guess the State", prompt="What's another state's name?")
```

* `screen.addshape(image)` + `turtle.shape(image)` — draw an image on the canvas.
* `screen.textinput()` — the pop-up input (Day 19).

---

### Summary Checklist

1. The map is a turtle shape — the whole game is a canvas + prompts.
