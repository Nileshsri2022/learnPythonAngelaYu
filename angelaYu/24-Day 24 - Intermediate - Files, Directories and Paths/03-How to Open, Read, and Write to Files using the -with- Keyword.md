So that way we can start saving our high scores into a file and retrieve it the next time we open up our program. Let&#x27;s start out by trying to do some of the simplest things with a file, reading and writing. Now I&#x27;ve created a new project using PyCharm called day-24, and I&#x27;ve created my main.py where we&#x27;re going to write our Python code. But in addition, I&#x27;m also going to create a new file which is going to be called my_file.txt. So this is going to be a text file. Now, inside this text file, I&#x27;m going to write some text. Hello, my name is Angela. And if you want, you can actually find this text file inside your project folder, and you can actually open it up with your native text editing software. So TextEdit on Mac or Notepad on Windows. And you can see it&#x27;s just a bunch of text. There&#x27;s nothing really special here. But what we can do using Python is that we can actually open up that file. So, notice how this method, open, is a inbuilt method. So you don&#x27;t have to import anything, you can use it directly. And it takes a number of inputs; the file that you want to open, the mode that you want to open that file in, and a whole bunch of other optional things that you can specify. In our case, I&#x27;m going to specify the name of my file as a string, so my_file.txt. So remember that extension. And then I&#x27;m going to open this file and I&#x27;m going to save it inside a variable called file. So when we hit run right now, nothing&#x27;s really going to happen. You&#x27;re not going to see anything happening, but behind the scenes, Python has already opened up this file and its ready for the next operation that you might want to do on that file. So the next thing I wanna do is I wanna read the file and this read method returns the contents of that file as a string. So we can now save it inside a variable called contents and I can go ahead and print out this contents. So when I hit run right now, you can see what gets printed out is the content from my_file.txt. And if I go ahead and modify my file to add some more lines and I hit run again, you can see that all of the lines are being printed once we&#x27;ve opened the file, we&#x27;ve read the file, and we print the contents that we have read. At the end of all of our work, what we have to do once we&#x27;re done with that file that we&#x27;ve opened we also have to close it. If there&#x27;s an open, there&#x27;s probably going to be a close. Now, why do we need to close the file? Well, once Python opens up that file, it basically takes up some of the resources of your computer. And at some point later on, it might decide to close it and free up those resources, but we don&#x27;t know when that&#x27;s going to happen and if it will happen. So instead, we&#x27;re going to tell it to close down the file manually using this line of code. It&#x27;s a similar concept to having lots and lots of tabs open in your browser. While it&#x27;s kind of convenient to have all of these tabs open, if you actually want your computer to perform at its best you actually want to only use as many tabs as you need. Every extra tab is going to add a little bit of burden to your computer and especially if you&#x27;re using a very heavy application like Chrome which likes to take up a lot of resources of your CPU and your computer. If you have more than 20 or 30 tabs, you&#x27;ll notice a significant decrease in the speed of your computer. So here&#x27;s a computer tip as well as Programming tip, always close down tabs that you&#x27;ve opened and always close out on files that you&#x27;ve opened. Now because it&#x27;s kind of hard to remember to close a file because we might be doing lots of other things in between the open and close, right? We might be writing to the file, we might be modifying it or reading it line by line or doing lots of different things. So instead, what many Python developers opt for is a different way of opening the file. We can use a &#x27;with&#x27; keyword. And &#x27;with&#x27; we can open this file and then we can open it as whatever it is we decide to name. So this you can name to anything. You can name it as f, you can name it as file. It&#x27;s basically the equivalent to that variable that we created earlier on which stored the opened file. Now we can indent the rest of this and I can delete this file.close. And you can see that it works exactly the same as before, but now we no longer have to remember to close our file just by adding some keywords here. This &#x27;with&#x27; keyword is going to manage that file directly. So as soon as it notices that we&#x27;re done with it, it&#x27;ll close down the file. It kinda makes me wish that something similar for tabs existed, but let&#x27;s get back to our Python code. So now that we&#x27;ve opened up my_file.txt, we&#x27;ve saved into a variable called file, we&#x27;ve read that file and saved the contents that we read into a variable called contents, and then we&#x27;ve printed it. Now, what if instead of reading the file, I wanted to write to it? Well, it&#x27;s just as simple. So we can get hold of our file and then call write. And we can put any sort of string inside this write method to put into our file. So let&#x27;s put some text, let&#x27;s call it new text. And I want this new text to be written into my_file.txt. And if we run the code as it is, you&#x27;ll notice that it doesn&#x27;t work cause it says that unsupported operation, this file is not writable. And this is because we opened up the file in read-only mode. So remember when we took a look at some of the parameters for this method open, one of them was called mode and by default, it&#x27;s set to read-only, so &#x27;r.&#x27; Now if we want to write to it, so make it editable, we have the change, the mode to &#x27;w&#x27; for write. So now if I run the code again, you can see that process finished with exit code zero which we know to mean that everything was successful. And if I take a look inside my_file.txt, all of the previous text got magically deleted and replaced with the new text that I wanted to write. Now, if you don&#x27;t want to delete everything that is in the file but you just want to add to it, then you can change this mode from &#x27;w&#x27; to &#x27;a&#x27; and &#x27;a&#x27; stands for append. So just as we like to use list.append and then we can add something to the end of the list, well, the same thing happens with appending and writing. So I can write my new text and I can add a new line, remember we can use \n to add a new line, and then add the new text. And now take a look at the after version when I hit run and we write this new line and new text by appending it to my file. It&#x27;s gone at the very end of the file here. Now, one of the important things you need to know when you&#x27;re writing files is when you try to open a file in write mode and that file doesn&#x27;t exist, then it&#x27;s going to actually create it for you from scratch. So let&#x27;s go ahead and create a file which I&#x27;ll call new_file.txt, make sure you&#x27;ve got the extension in there. And we have the mode as write set. Because this new_file.txt doesn&#x27;t exist in this folder, then it&#x27;s actually going to create it for us. So now when I hit run, you can see that once this goes through, that new file gets created and the new text has been written inside. Now, remember this only works when you&#x27;re in the write mode and when that file doesn&#x27;t currently exist. So those are some basic ways of working with the file system. We can open and read, we can open and write. And by using these different modes, append, read, or write, we can define what it is that we want to do with that file that we&#x27;ve opened.
