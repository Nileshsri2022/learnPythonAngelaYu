# Day 6 Goals- what we will make by the end of the day

---

### 1. Skills Covered on Day 6

* **Defining and calling functions** — `def name():`
* Code blocks and **indentation** in depth
* **`while` loops** — looping while a condition holds (the second flavour of loop)
* Combining functions + `while` loops + `if` statements to solve problems

All of today's practice happens in **Reeborg's World** — a robot simulator very
similar to Karel the Robot, a classic learn-to-code tool.

---

### 2. The End-of-Day Project: Escaping the Maze

Teach the robot to escape **any randomly generated maze**. The maze layout never changes,
but the robot's **start position and direction are random every time** — so hard-coding
moves is impossible. You need an *algorithm* (a strategy) that works from anywhere.

---

### Summary Checklist

1. Functions package code into reusable named blocks.
2. `while` loops repeat **as long as** a condition is true.
3. The maze is won by strategy (an algorithm), not by memorising steps.
