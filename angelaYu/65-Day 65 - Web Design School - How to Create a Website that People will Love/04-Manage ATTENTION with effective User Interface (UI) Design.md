# Manage ATTENTION with effective User Interface (UI) Design

---

### 1. Hierarchy: Tell the Eye Where to Go First

Shown a page, people read the biggest, boldest, most contrasted thing first. UI design
uses that deliberately.

Establish hierarchy with:

| Tool | Example |
|------|---------|
| **Colour** | a bright accent button on a muted page (ASOS: grey/white + a green "Add to bag") |
| **Size** | Coinbase's huge "Buy and sell cryptocurrency" headline, then an even bigger email input |
| **Weight/position** | bold headings above light body copy |

Bad hierarchy = a birthday invitation written as one paragraph, so the reader must hunt for
the date and place.

---

### 2. Layout: Break Up the Wall of Text

* A single block of text all the way down the page is dull; intersperse images, vary sizes
  and shapes.
* Wikipedia is the classic "functional but bland" example — nothing wrong with the content,
  nothing engaging about the layout.

---

### 3. Alignment and Line Length

* Everything on a page should relate to a consistent edge or axis — misaligned elements
  look accidental.
* **Optimal line length: 40–60 characters.** Longer, and the eye loses its place tracking
  back; shorter, and the reading feels choppy.
* Constrain the paragraph width with `max-width` (e.g. `65ch`) rather than letting text run
  edge to edge.

---

### 4. White Space

Empty space is a design element, not wasted space.

* Luxury shops display two handbags in a big window → perceived value goes up.
* Discount stores cram the window full → perceived value goes down.
* The same works digitally: one product with breathing room looks like Apple made it; the
  same product crowded with "New!", "Only $20!", "100% off!" looks cheap.

> **Tip:** When a page feels wrong, try *removing* something and adding padding before you
> try adding anything.

---

### 5. Design for Your Audience

The rules bend for the audience:

* A kids' concert poster can be loud, colourful and playful.
* The same event for adults can be minimal and serious.
* A crypto site needs trust cues; a teen fashion brand needs energy.

Flexibility is the skill: one style does not fit every product.

---

### Summary Checklist

1. Hierarchy = colour, size and weight guiding the eye in a deliberate order.
2. Break up text with images and varied layout; avoid monotony.
3. Keep alignment consistent; aim for 40–60 characters per line.
4. White space makes designs look expensive — use it generously.
5. Always design for the specific audience, even if that means bending the rules.
