# Programming is not Memorising

---

### 1. The Message: Programming is Not Memorising

*"I can't remember the exact syntax from Day 1 — does that mean I've learned nothing?"*
No. Programming is like video-game combos: you don't memorise them, you build **muscle
memory through reps** — and even professionals look things up constantly.

* What matters: recognising *what* tool exists and *where* to find it.
* Syntax recall fades without use — that's true for everyone.
* Twenty days in: a fifth of the course done. That's real progress. 🎉

---

### Summary Checklist

1. Don't test yourself on recall; test yourself on *building*.
2. Look things up freely — docs are part of programming.
