### Summary

Now that we&#x27;ve got our app working, you might think we&#x27;ve reached the end of today&#x27;s lessons, but there&#x27;s just one final thing I want to talk to you about. And that is the environment. Not the environment as a whole, but more precisely environment variables. Now what our environment variables anyways? If you go into your PyCharm project and you go into this tab where it says &quot;Terminal&quot;, here if you type in env (set on Windows) and hit &quot;Enter&quot;, you can see a whole bunch of variables. So you&#x27;ve got a key and a value and in between there is just a single equal (=) sign. So these are the different variables that are set in the environment in which your code is run. These variables have values which are strings which can be used in our applications or our code. Now inside Python anywhere you can also type env and you can see some slightly different environment variables which are relative to the Python anywhere environment. What exactly all these environment variables used for? Well, there&#x27;s two major use cases. One is for convenience. Normally when you deploy a large application, the process is quite complicated. And once you&#x27;ve done it, you kind of don&#x27;t want to mess around with the code base and update the code files like your main.py for example. Instead, you could have these environment variables, which you can change. For example, if you had an application that was sending you emails out to your clients, then your client base emails might change day to day. So certain variables that are being used in your code base could be set as environment variables and you can modify those variables without having to touch the code. A second reason might be for security. So when you&#x27;re developing software, you might be uploading your code based somewhere, for example to store it online or to a service like PythonAnywhere. And it&#x27;s usually not a good idea to have things like your authentication keys or your API keys to be stored in the same place as the rest of your code. That&#x27;s where environment variables come in. So environment variables essentially allow us to separate out where we store our keys, our secret stuff, and various other variables away from where our code base is located. In our case, it doesn&#x27;t really matter because we haven&#x27;t got a paid account anywhere in here. It doesn&#x27;t really matter if somebody steals our auth token or our API key, because none of those are linked to our payment details. Now, however, if we were to upgrade our accounts on open weather map&#x27;s API or on Twilio&#x27;s API, then we definitely want to keep these two things secret; auth token and the API key. Instead of having it located in the same place where we&#x27;ve got our code base which means you might accidentally upload it somewhere on the internet where other people can see it, instead, we can store these two things as environment variables. We can create an environment variable by simply typing export and then the name of the variable which I&#x27;ll call OWM _API_KEY. And then it&#x27;s really important that we have no spaces, but just a single equal sign. And then we&#x27;re going to store everything that&#x27;s in between the quotation marks. So I&#x27;m going to copy that from over here, and I&#x27;m going to paste that in here. Once I&#x27;ve exported that and then if I hit &quot;env&quot; again, you&#x27;ll see now in this updated environment you can see that environment variable go in right there. And now we can tap into that environment variable in any of the code that we run from this particular environment. To do that we have to use this os module that we&#x27;ve already got. So I&#x27;m going to delete everything that&#x27;s currently stored in the API key. And instead, I&#x27;m going to tap into os.environ, and then I&#x27;m going to use a method called get to get the value of a particular environment variable. The name is everything that&#x27;s before the equal sign. So let&#x27;s go ahead and paste it in here. And now when I run this code, so using python3 and then the name of the file, you can see that it successfully runs queuing our message into Twilio. Now go ahead and do the same thing with the auth token. You want to save this as an environment variable code auth_token in all caps, similar to what we&#x27;ve got here. And you want to store this value in the environment variable. Pause the video and give that a go. All right. So we&#x27;re going to follow the exact same thing that we did before. We use the export keyword and then we type in the name of the environment variable which is going to be AUTH_TOKEN. And then really importantly, we just have an equal sign, no spaces, and we&#x27;re going to store this value without the double-quotes and we&#x27;re going to put it in here. Now in our environment variables, you can see we&#x27;ve got our open weather map API key. And if we scroll up a bit more, you can see our auth token as well. So now we can replace this string with our os.environ.get and then we pass in the name of the key which is AUTH_TOKEN. And now let&#x27;s run our code again with python3 main.py. And you can see it&#x27;s still works as before. But now if somebody comes across this particular code base on the internet, they won&#x27;t be able to use our Twilio account or our open weather map account because both of these keys are now hidden. Let&#x27;s go ahead and hit save. So now we&#x27;re going to do the same thing, but at the point where we run our code from our task scheduler. Now, afterward, I&#x27;m going to use a semi-colon to denote a new line and then I&#x27;m going to export the next key. Scrolling up, we can see our auth token right here so we&#x27;re going to copy that as well and we&#x27;re going to export that as the other environment variable. The bigger problem is when you upload your own code to places like Git Hub or a BitBucket, basically places that are essentially a Dropbox for code. And when you have it on there, because your code could be public, that&#x27;s where the problem happens. If people look at your code file and they see that you&#x27;ve got API keys in there, then they might steal them.
