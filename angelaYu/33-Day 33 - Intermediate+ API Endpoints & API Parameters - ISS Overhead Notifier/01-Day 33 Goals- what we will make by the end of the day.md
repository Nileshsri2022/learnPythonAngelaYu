# Day 33 Goals- what we will make by the end of the day

### 1. Skills Covered on Day 33

* **APIs** — what they are and why everything uses them
* **Endpoints** — URLs that serve data
* **`requests`** — making GET calls from Python
* **HTTP response codes** — 1xx–5xx families and `response.raise_for_status()`
* **API parameters** — customising what a request returns

### Summary Checklist

1. API = a waiter between your program and someone else's data/service.
2. `requests.get(url)` + `.json()` is the core workflow.
3. Parameters (like lat/long) tailor responses to you.
