# Optional (NOT FREE any more)- Run Your Python Code in the Cloud!

---

### 1. The Message

Alternatives to GitHub Actions for always-on scripts — **PythonAnywhere** (used later in
the course) and paid platforms like Heroku/AWS. Note: the free tiers that existed when
this course was recorded have mostly disappeared — GitHub Actions (previous lesson) is
the recommended free path today.

---

### 2. The Pattern

Whatever the host, the shape is the same:

1. Upload the code (repo or upload).
2. Set the schedule (cron or always-on task).
3. Provide secrets as environment variables.
