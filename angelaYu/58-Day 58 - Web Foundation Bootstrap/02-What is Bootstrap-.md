Here is a structured breakdown of this lesson on what Bootstrap is.

---

### 1. The Framework

Created at Twitter in 2010 (Mark Otto & Jacob Thornton). Include it via CDN and every
Bootstrap class works:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
      rel="stylesheet">
```

```html
<button class="btn btn-success">Download</button>
```

One class pair = a fully styled, hover-animated button. Every default colour has a
class: `btn-primary`, `btn-danger`, `btn-warning`, …

---

### 2. Why It Won

* **Pre-made components** — instant professional UI.
* **12-column responsive grid** — layout that adapts to any screen.
* Battle-tested on millions of sites.

---

1. CDN link + classes = Bootstrap.
