Here is a structured breakdown of the Day 58 project — TinDog.

---

### 1. The Task

A complete startup landing page for **TinDog** ("Tinder, but for dogs") — navbar,
hero with download buttons, features grid, press row, pricing columns, footer —
using only Bootstrap components and utility classes.

---

### 2. The Build Steps

1. CDN links: Bootstrap CSS + JS bundle + Font Awesome (icons).
2. **Navbar**: `navbar navbar-expand-lg navbar-dark` + brand + links.
3. **Title section**: `row` with a `col-lg-6` for the pitch + buttons, one for the
   iPhone mock-up image.
4. **Features**: three `col-lg-4`s — icon, heading, blurb.
5. **Press**: a row of company logos.
6. **Pricing**: three cards in `col-lg-4`s — Chihuahua / Labrador / Mastiff tiers.
7. **Footer**: social icons + copyright.

---

### Summary Checklist

1. Layout (grid) + components (cards/buttons) + utilities (text-center, padding).
2. Runnable version: [`index.html`](index.html) — open it, or serve via Flask.
