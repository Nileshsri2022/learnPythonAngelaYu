Here is a structured breakdown of this lesson on the goals for Day 58.

---

### 1. What Today Covers

An introduction to **Bootstrap**, the most widely used CSS framework, and a full startup
landing page built with it:

| Topic | What you'll be able to do |
|-------|---------------------------|
| What Bootstrap is | explain frameworks, pros/cons, and when *not* to use one |
| Layout | build responsive grids with the 12-column system |
| Components | buttons, cards, navbars straight from the docs |
| Project | a complete responsive **TinDog** landing page |

---

### 2. Why Learn a Framework?

Bootstrap was created at Twitter in 2010 by Mark Otto and Jacob Thornton. It ships
pre-written CSS for common components and a responsive layout system, so you get
professional-looking, mobile-first pages fast — without inventing button styles for the
hundredth time.

---

### 3. The Project: TinDog

A fake startup landing page — "Tinder for dogs":

* hero section with headline, app-store buttons and an iPhone mock-up,
* features, testimonials, pricing plans,
* animated gradient background,
* footer.

Everything is assembled from Bootstrap **examples and snippets**, then customised with a
little of your own CSS.

---

### 4. What You Need to Bring

* Day 41–44 HTML/CSS (tags, classes, the box model, media queries).
* A willingness to explore the Bootstrap docs — finding the right snippet is the actual
  skill being trained today.
* The starter files (`index.html`, `images/`, `style.css`) from the course resources.

---

### Summary Checklist

1. Bootstrap = pre-made CSS + components + a responsive grid.
2. Uses the CDN: one `<link>` for CSS, one `<script>` for JavaScript behaviour.
3. TinDog project = assemble and customise Bootstrap snippets.
4. Docs-driven development is the workflow: find it, copy it, adapt it.
