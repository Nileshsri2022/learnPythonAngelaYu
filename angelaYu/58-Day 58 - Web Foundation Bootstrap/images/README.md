# images/

Drop the TinDog image assets here (from the course resources):

| File | Used by |
|------|---------|
| `iphone.png` | hero section (app mock-up) |
| `dog-img.jpg` | testimonials section |
| `dog.png` | optional feature/testimonial card |

The paths in `index.html` already point at these filenames, so simply adding the files
makes the page complete. Any missing image renders as a broken-image icon — that's the
signal that a filename doesn't match.
