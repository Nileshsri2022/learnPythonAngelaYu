### 3. Choosing What to Learn Next

1. **What does your goal need?** A job posting is a syllabus — read it.
2. **What did you enjoy most?** Back-end, front-end, data, mobile, automation.
3. **What's the smallest next step?** One project with the new technology beats a whole
   course you never finish.
4. **Do you own the fundamentals?** HTML, CSS, Python, Git, SQL, REST — those transfer
   everywhere; frameworks don't.

---

### 4. Don't Collect Courses

The graveyard of unfinished courses is real. Better plan:

* finish the portfolio projects from Day 83 first,
* then pick **one** new technology that a specific project needs,
* learn it by building that project.

You already know how to learn a technology: read the docs, follow a quickstart, build
something small, read the errors, iterate (Days 54–57 taught exactly this).

---

### Summary Checklist

1. This lecture is a pointer to further courses — not new technique.
2. Choose the next technology by goal, then interest, then one small project.
3. Finish something before starting the next thing.
4. Fundamentals transfer; frameworks expire.
