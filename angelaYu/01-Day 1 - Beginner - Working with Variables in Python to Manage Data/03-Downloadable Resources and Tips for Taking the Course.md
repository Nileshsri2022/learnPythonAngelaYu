# Downloadable Resources and Tips for Taking the Course

---

### 1. Downloadable Resources

* The **full course curriculum as a PyCharm project** — every day comes as a folder with
  starting files (e.g. `main.py`) so you always run exactly what you see on screen.
* **Slides and cheatsheets** are attached to individual lectures throughout the course.
* Links to the **live project previews** (e.g. repl.it demos) so you can try each day's
  final program before you build it yourself.

---

### 2. Tips for Taking the Course

1. **Type out all the code yourself** — never copy-paste. Muscle memory matters.
2. **Ask questions** in the Q&A when stuck; search first, someone has hit the same bug.
3. **Google and StackOverflow are your friends** — professional programmers look things up every day.
4. **Keep a consistent daily schedule** — the "100 days" format works best when you show up every day.
5. **Break things on purpose** — change the code, run it, see what errors appear. Debugging teaches faster than watching.

---

### Summary Checklist

1. Download the day's exercises and open them in PyCharm.
2. Code along actively instead of passively watching.
3. Use the Q&A, Google, and documentation when stuck — that's real-world practice.
