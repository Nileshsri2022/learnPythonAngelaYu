# What you're going to get from this course

---

### 1. The Course in One Line

**100 Days of Code™: The Complete Python Pro Bootcamp** — a project-based bootcamp by
Dr. Angela Yu that takes you from complete beginner to professional Python developer in
100 days, one day (and one project) at a time.

---

### 2. What You Get

* **100 days** of structured lessons — Beginner → Intermediate → Advanced → Professional.
* **100+ projects**, from small scripts to full portfolio pieces (games, GUI apps, web apps, APIs, data science).
* **Real code you write every single day** — every concept is immediately applied.
* A **portfolio** by the end: websites, automation bots, machine-learning projects, REST APIs and more.

> **Note:** The philosophy of the course is *learn by building*. You don't just watch —
> you code along, then build the day's project yourself before watching the solution.

---

### 3. How the Learning is Structured

| Stage | Days | Focus |
|-------|------|-------|
| Beginner | 1–14 | Variables, data types, control flow, loops, functions, debugging |
| Intermediate | 15–40 | GUIs, OOP, files, APIs, web scraping, automation |
| Web / Advanced | 41+ | HTML/CSS, Flask, SQL, deployment, data science |

---

### Summary Checklist

1. A **project-based** Python bootcamp — one day, one set of skills, one project.
2. Progresses from **absolute beginner** to **job-ready portfolio**.
3. The best way to take it: **code along every day** and don't skip the projects.
