Here is a structured breakdown of this "START HERE" lecture and how to begin the course.

---

### 1. Purpose of This Lecture

This is the official starting point of the course. It explains how the course is organised
and what to do **before** writing your first line of Python.

---

### 2. Getting Set Up

* Every day's exercises are provided as a **downloadable PyCharm project** (see the
  resources of the first day) so you can follow along exactly as shown in the videos.
* You can also code in an **online IDE** — no installation needed — but working locally in
  **PyCharm** is the recommended, professional setup.

---

### 3. How to Work Through Each Day

1. Watch the day's **goals** lecture to see what you'll build.
2. Code along with the concept lectures — **type everything yourself**.
3. Attempt the **daily project** *before* watching the solution walkthrough.
4. Compare your solution, fix bugs, and move on.

> **Tip:** Don't aim for perfection on the projects — aim to *finish* them. Every day
> builds on the last, so consistent daily progress beats a perfect Day 1.

---

### Summary Checklist

1. Download the course materials / set up PyCharm (or use the online IDE).
2. Follow the daily rhythm: goals → code-along → project → solution.
3. Type all the code yourself — that is where the learning happens.
