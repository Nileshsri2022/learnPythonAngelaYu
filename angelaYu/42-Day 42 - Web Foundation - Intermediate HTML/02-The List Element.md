# The List Element

---

### 1. Ordered and Unordered

```html
<ol>                       <!-- ordered list: numbers -->
    <li>Preheat the oven</li>
    <li>Mix the batter</li>
</ol>

<ul>                       <!-- unordered list: bullets -->
    <li>Flour</li>
    <li>Sugar</li>
    <li>Eggs</li>
</ul>
```

* `<ol>` — order matters (steps, rankings).
* `<ul>` — order doesn't (ingredients, features).
* `<li>` — a list item; always *inside* an `ol`/`ul`.

---

### Summary Checklist

1. `ol` numbered, `ul` bulleted, `li` items.
2. The list wrapper picks the marker; `li` is the content.
