Here is a structured breakdown of this lesson on anchor elements.

---

### 1. The Link

```html
<a href="https://www.google.com">Click here to search Google</a>
```

* `<a>` — anchor; `href` — an **attribute**: extra configuration written inside the
  opening tag (`name="value"`).
* The content between the tags is what the user sees and clicks.

---

### 2. Attribute Anatomy

```html
<a href="about.html">About</a>          <!-- relative: same site -->
<a href="https://..." target="_blank">Open in a new tab</a>
```

* Attributes only exist on the opening tag.
* Different elements accept different attributes — `href` for `a`, `src` for `img`, etc.

---

### Summary Checklist

1. Attributes = settings on the opening tag.
2. `href` makes `<a>` a hyperlink; `target="_blank"` opens new tabs.
