Well, one of the biggest downsides is something called, Class Bloat. Using external CSS frameworks, because we're adding everything into the classes, then very quickly you end up with what's called class bloat, where you have a lot of styling going into the actual HTML file and it looks a lot less clean than if we had just used something like Grid or Flexbox, where we have all of our predefined classes and we go easy on the classes that we add in to our HTML file. The other downside is customization. If you want to build a website where you want to have full control over every pixel and layout and everything to be exactly the way you designed it, then external CSS frameworks is probably not the way to go because in order to customize each and every component, it can be really time consuming. So when should you use the CSS frameworks like Bootstrap and when should you not? Well, when you are building a mobile-first responsive website that you want to put online very quickly and access beautiful components designed by professional designers, keeping everything on your website looking slick and uniform, then you probably want to consider using Bootstrap. But if you're building a very simple website, where you just need HTML and CSS and you can quickly throw it up, or if you're building a really complex custom design website and you want complete control over the design, then it's probably not a good idea to use an external CSS framework like Bootstrap.
