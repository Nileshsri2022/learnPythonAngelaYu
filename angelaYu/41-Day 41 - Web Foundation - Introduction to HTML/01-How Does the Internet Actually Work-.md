Here is a structured breakdown of this lesson on how the internet works.

---

### 1. The Journey of a Web Page

1. You type a URL — a human-friendly address.
2. The **Domain Name System (DNS)** — the internet's phone book — translates the name
   (`google.com`) into a **server IP address**.
3. Your browser sends an **HTTP request** to that IP.
4. The server responds with files (HTML, CSS, images…) as an **HTTP response**.
5. The browser renders them.

---

### 2. The Key Players

| Piece | Role |
|-------|------|
| DNS | name → IP address lookup |
| Server | a computer that listens and responds |
| HTTP/HTTPS | the request/response protocol (S = encrypted) |
| Browser | sends requests and renders responses |

---

### Summary Checklist

1. Name → DNS → IP → request → response → rendered page.
2. HTTPS is HTTP wrapped in encryption.
