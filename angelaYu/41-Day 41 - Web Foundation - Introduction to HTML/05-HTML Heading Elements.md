Here is a structured breakdown of this lesson on heading elements.

---

### 1. The Six Headings

```html
<h1>Heading level 1</h1>
<h2>Heading level 2</h2>
<h3>Heading level 3</h3>
<h4>Heading level 4</h4>
<h5>Heading level 5</h5>
<h6>Heading level 6</h6>
```

* Size shrinks from `h1` to `h6`.
* Headings define the **document outline** — one `h1` per page, `h2` sections under it,
  `h3` sub-sections, like a book's chapter structure.

> **Note:** Use headings for *structure* ("this is a section title"), not because you
> want smaller text — sizing is CSS's job, and screen readers navigate by headings.

---

### Summary Checklist

1. Six levels; `h1` = the page's title, `h6` = the deepest sub-point.
2. Headings are semantic structure, not text styling.
