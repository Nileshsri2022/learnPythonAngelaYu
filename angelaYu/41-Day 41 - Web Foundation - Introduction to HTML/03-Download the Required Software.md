# Download the Required Software

---

### 1. The Web-Dev Toolkit

* **Chrome** — the reference browser (its DevTools, `F12`/right-click → Inspect, are the
  web developer's microscope).
* **Visual Studio Code** — the editor of the web world (PyCharm works too, but VS Code
  is the industry default for front-end).
* **Live Server** (VS Code extension) — auto-reloading local server so you see changes
  the instant you save.

---

### 2. Project Setup

```text
movie-ranking/
└── index.html
```

Right-click → *Open with Live Server* → edit, save, watch the browser update.

### Summary Checklist

1. Chrome + VS Code + Live Server = the day-1 front-end setup.
