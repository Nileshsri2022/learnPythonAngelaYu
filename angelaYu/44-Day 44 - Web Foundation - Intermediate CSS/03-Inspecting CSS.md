Here is a structured breakdown of this lesson on inspecting CSS.

---

### 1. Chrome DevTools for CSS

Right-click → **Inspect** opens DevTools:

* **Elements panel** — the live DOM; click any node to see its rules.
* **Styles pane** — every rule affecting the element, in cascade order, with struck-out
  rules that lost.
* The **box-model diagram** at the bottom shows margin/border/padding/content
  interactively.

---

### 2. Why This Matters

* Debug: "why is this blue?" — the styles pane answers in cascade order.
* Experiment: edit values live; nothing is saved — refresh resets.
* Screenshot "borrow": inspect any website's CSS to learn how effects are done.

---

### Summary Checklist

1. Inspect = X-ray for any page's CSS.
2. Changes in DevTools are temporary — playground, not editor.
