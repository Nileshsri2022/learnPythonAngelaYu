### 1. The Message

**This course is not about typing out code.** Typing along is the *minimum*; the learning
happens when you:

* attempt every step **before** the solution,
* rebuild old projects from memory,
* change and extend what you built.

If you can rebuild Pong or Snake from a blank file, you own it. If you can only follow
along, re-run the day.
