Here is a structured breakdown of this lesson on using the starter code.

---

### 1. What the Starter Project Gives You

A PyCharm project folder with:

* `main.py` — the game loop skeleton with TODO comments.
* Empty class files to fill in: `player.py`, `car_manager.py`, `scoreboard.py`.
* A demo `.gif`/video of the finished game to copy the behaviour from.

---

### 2. Working With TODO-Driven Projects

1. Run the starter — see exactly what exists.
2. Watch the demo of the **finished** game (Step 1).
3. Work through the TODOs **in order**, running after each one.
4. Only open a solution lecture after genuinely attempting the step.

This is the professional workflow — you'll get ticket-style specs and build against them.

---

### Summary Checklist

1. Starter code = realistic job conditions: partial codebase + requirements.
2. TODO order matters — each step builds on the last.
