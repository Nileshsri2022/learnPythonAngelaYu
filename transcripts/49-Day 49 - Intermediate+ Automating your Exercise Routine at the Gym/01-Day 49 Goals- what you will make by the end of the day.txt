This is handy when you've run your selenium code to book gym classes, and you'd like to run the code again after making a small change. In this case, it's a good idea to have the database in exactly the same state before you ran your code for the first time. This is why I've got some information at the top to show what's in the database. And I've got two buttons at the bottom. You can see the database in Chrome's developer console. If you go to the application tab, you should see that under storage there is an Indexeddb with the gyms data. If you open a new browser or a different user profile, then you will have a different copy of this database. What this means is that if you register a user or make a booking in one profile, that booking won't show up in the other profile. This is why, as a first step, we'll make sure that every time selenium runs, we'll use the same Chrome profile. So that's your profile picture icon here. Most people just have one. But in case you're somebody like me which like 3 or 4, then this is something you should look out for. This way your bot will always see the same bookings and user data.
