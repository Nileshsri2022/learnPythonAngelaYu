Lecture: Install Git Bash on Windows
----------------------------------------

All right guys, in this lesson, we'll go through the installation steps to install Git Bash and Git on Windows. Mac already comes with Bash pre-installed, so if you're working on a Mac, you can skip this lesson and head over straight to the next lesson. Now, the first thing you're going to do is you're going to navigate to Git for Windows and you're going to download the Git SCM. Now, once that's downloaded, go ahead and open up the installer and select Yes. And then you're going to agree to the license by clicking Next, select the location where you're going to install Git. On this next step where it asks you to select which components should be installed, make sure that this checkbox next to Git Bash is selected and is checked as yes. Now go ahead and leave the defaults for the rest and click Next, and then leave the default Git as the folder and click Next, and then keep clicking Next and going with the default selected options. Select Next, and Next, and Next. (chuckles) And just basically keep selecting Next and keeping the default selections from the installer. Now, once installation is completed, let's make sure that it works. So let's open up the VS Code and open up a terminal, and you can find that on the top menu. Click Terminal, New Terminal. And then in this new terminal, click on that dropdown button next to the plus sign and select Git Bash. Now you should see something similar to this with a dollar sign in the terminal. Now, in order to configure VS Code to make Git Bash your default shell, we have to go to the command palette, and we can find that by going to View, Command Palette. And then in the command palette, we're going to search for Select Default Profile. And once that comes up in the dropdown, select it, and then select Git Bash. And this is going to set it so that, every time you open up a new terminal, we're working with Git Bash as the selected terminal. So let's try it out. Let's click... Close down that terminal, select a new one, and you can see Bash showing as the profile for our terminal. And there you have it.
