Hey, guys. Welcome to Day 12 of 100 Days of Code. Now today we're going to be building a Number Guessing Project. And we're going to be learning all about Scope. So if you take a look at the final demo project for Day 12, you'll see that we've got a Guess The Number game. So, "Welcome to the Number Guessing Game! I'm thinking of a number between 1 and 100." Now in the demo, there is a little bit of answer text which you won't have in your final game, but this is just to make it a little bit easier for us to test this game. So the correct answer is 100, which we already know. Now we're asked to choose a difficulty, 'easy' or 'hard'. Now if we choose easy, it means we have 10 attempts to guess the number. And if we guess a number and it's too low, it'll tell us that it's, 'Too low'. And if we guess a number that is too high, then it will be, 'Too high', until we somehow figure out the correct answer, which in this case happens to be 100. Now, if we go ahead and try the hard mode, you can see we only have 5 attempts to guess the answer, and we have to be able to get there using these clues of low or high to try and guess the correct answer. So this is what we're going to be building, and in the process, we're going to be covering a lot about Scope, about Global variables, about a lot of the stuff that we've sort of started to think about and to use in our code, but formerly we haven't yet really approached.
